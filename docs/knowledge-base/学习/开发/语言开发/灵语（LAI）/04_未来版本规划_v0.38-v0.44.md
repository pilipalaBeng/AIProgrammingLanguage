## 当前 v0.37 基线

v0.37 使用单一 checked i32 模式：纯静态零除和中间溢出由编译期诊断，动态 C 加减乘、取负、除、取模及复合赋值经 private runtime helper 检查，失败写入 `stderr` 后以 `EXIT_FAILURE` 退出。`for` 三值各求值一次，动态 step 必须为正，范围感知推进可正常到达 i32 上界；内部前缀按每次生成避开用户名称。`step` 仍是保留关键字。LLVM 只支持纯静态顶层整数 `print` 子集，动态值与控制流仍不支持。示例是 `examples/runtime_integer_safety.ly`。

## 路线图使用规则

- 版本号表示小范围阶段目标，不能覆盖当前 v0.37 的事实边界。
- 每次只推进一个可运行、可测试的闭环；先写设计/计划，再修改语言实现。
- 新增用户可见语法时，先向用户给出 2-3 个有意义候选、示例、利弊、与 LAI 一致性和明确推荐。
- 未来数组命名草案与远期愿景只可作为设计输入，不能写成“已支持”。
