# LAI 当前能力与运行方式

最后同步：2026-07-29。当前版本是 v0.38。

## 已实现语言能力

| 分类 | v0.38 支持 |
| --- | --- |
| 基础类型 | `string`、`int`、`bool`；`int` 源码静态范围为 `-2147483648..2147483647`。 |
| 表达式 | 字符串、整数、布尔、变量、调用、括号、一元 `+`/`-`、`+ - * / %`、比较和 `not` / `and` / `or`。 |
| 比较 | `< <= > >=` 仅两个 `int`；`== !=` 接受同类型的 `int`、`bool`、`string`。比较结果为 `bool`，比较链会报错。 |
| 布尔逻辑 | `and`、`or`、`not` 是保留关键字，无 `&&`、`||`、`!` 别名；operand 和结果严格为 `bool`，无 truthiness。 |
| 函数 | 必须有 `fn main() { ... }`；其他函数可带显式类型参数和 `int`/`string`/`bool` 返回类型；支持 guard clause 和分支/循环中的路径级早退。 |
| 返回检查 | 返回值函数的所有可达路径必须返回；第一条不可达语句报 `unreachable statement`；发散路径不能代替返回。 |
| 语句 | `let`、已有变量赋值、`+= -= *= /= %=`、`print`、`return`、`if / else if / else`。 |
| 控制流 | `while`、`for i from ... to ...`、`step`、`through`、`break`、`continue`。仅字面量 `true` 及其嵌套括号可证明静态无限 `while`。 |
| 整数安全 | 单一 checked i32 模式；纯静态零除和中间溢出在编译期诊断，动态 C 加减乘、取负、除取模及复合赋值失败写 `stderr` 后 `EXIT_FAILURE`。 |
| 循环安全 | `for` start/end/step 各求值一次；动态 step 在进入循环前必须为正，范围感知推进可正常完成 i32 上界。 |

共享 checker 用 `fallthrough`、`return`、`break`、`continue`、`diverge` 表示语句块可能结果。guard clause 的分支可以先返回，外层后续语句继续覆盖未返回路径；若所有分支都终止，后续第一条语句就是不可达错误。普通 `while` 和 `for` 仍保守，因为循环可能一次也不执行；静态 `while true` 中出现可达 `break` 时仍需要循环后的兜底返回。

字符串相等使用内容比较：C 后端生成 `strcmp(left, right) == 0` 或 `!= 0`。表达式优先级为算术高于比较，比较高于 `not`，`not` 高于 `and`，`and` 高于 `or`；`and` / `or` 从左到右短路。

## C 与 LLVM 后端对照

| 维度 | 默认 C 后端 | 实验性 LLVM 文本 IR 后端 |
| --- | --- | --- |
| 选择 | 默认；`--backend c` | `--backend llvm` |
| 覆盖范围 | 完整 v0.38 C 语言路径 | 经共享 checker 静态安全检查的空 `main` 或顶层纯整数 `print` 子集 |
| v0.38 示例 | `examples/general_early_return.ly` 输出 `-1`、`0`、`1`、`7`、`8` | 第 1 行因 `FunctionDef` 不支持而拒绝该示例 |
| 不支持 | 无额外后端限制 | 动态值、变量、赋值、比较、布尔、字符串、控制流和用户函数 |
| 构建 | 生成 C 后调用 `clang` | 生成 `.ll` 后调用共享 `clang` |

`--backend {c,llvm}` 默认选 `c`。共享 checker 先完成语义、类型、控制流和静态 i32 检查，再进入后端。LLVM 只是实验性子集，不能把它当成 v0.38 全量后端。

## 运行与验证

环境通常需要 Python 3.12+、`clang` 在 `Path` 中；Windows 还需要可用的 MSVC/Windows SDK 链接环境。

```powershell
python -m unittest discover -v
python lai_compiler.py main.ly --run
python lai_compiler.py examples/basic_comparisons.ly --run
python lai_compiler.py examples/boolean_logic.ly --run
python lai_compiler.py examples/runtime_integer_safety.ly --run
python lai_compiler.py examples/general_early_return.ly --run
python lai_compiler.py examples/general_early_return.ly --backend llvm
python lai_compiler.py examples/unary_integer.ly --backend llvm --run
python lai_compiler.py examples/llvm_minimal.ly --backend llvm --run
python lai_compiler.py examples/llvm_arithmetic.ly --backend llvm --run
```

v0.38 发布基线为 399 项单元测试通过。C 早退示例应成功运行；LLVM 早退示例应以明确的 `FunctionDef` 能力错误失败，这也是后端边界验证。

## 未实现边界

- 裸 `return`、void/main 返回仍未实现。
- 通用常量折叠未实现；`not false`、比较或逻辑表达式不会被当成静态 `true` 循环证明。
- 普通 `while` 和 `for` 的必执行证明、静态非空 `for` 证明未实现。
- 布尔逻辑符号别名 `&&` / `||` / `!` 和非 `bool` truthiness 未实现。
- 数组及其遍历、倒序 `for`、负步长、带标签 `break` / `continue`、`count++` 未实现。
- 浮点数、动态范围分析、字符串排序、隐式转换、默认/命名/可变参数、重载、变量类型标注、GC、JIT、并发未实现。
- 完整 LLVM 后端未实现；变量、用户函数和控制流仍会报明确能力错误。

`step` 仍是保留关键字。下一版是 v0.39 显式类型固定长度数组核心；多维数组插入 v0.41，剩余编号队列为 v0.39-v0.45，共 7 个版本。数组仍未实现。
