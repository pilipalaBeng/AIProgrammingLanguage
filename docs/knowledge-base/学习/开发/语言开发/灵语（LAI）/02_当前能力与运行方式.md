# LAI 当前能力与运行方式

最后同步：2026-07-28。当前版本是 v0.37。

## 已实现语言能力

| 分类 | v0.37 支持 |
| --- | --- |
| 基础类型 | `string`、`int`、`bool`；`int` 源码静态范围为 `-2147483648..2147483647`。 |
| 表达式 | 字符串、整数、布尔、变量、调用、括号、一元 `+`/`-`、`+ - * / %`、比较和 `not` / `and` / `or`。 |
| 比较 | `< <= > >=` 仅两个 `int`；`== !=` 接受同类型的 `int`、`bool`、`string`。比较结果为 `bool`，比较链会报错。 |
| 布尔逻辑 | `and`、`or`、`not` 是保留关键字，无 `&&`、`||`、`!` 别名；operand 和结果严格为 `bool`，无 truthiness。 |
| 函数 | 必须有 `fn main() { ... }`；其他函数可带显式类型参数和 `int`/`string`/`bool` 返回类型；调用可作为语句或表达式。 |
| 语句 | `let`、已有变量赋值、`+= -= *= /= %=`、`print`、`return`、`if / else if / else`。 |
| 控制流 | `while`、`for i from ... to ...`、`step`、`through`、`break`、`continue`。`to` 不含终点，`through` 包含终点；循环变量局部。 |
| 整数安全 | 单一 checked i32 模式；纯静态零除和中间溢出在编译期诊断，动态 C 加减乘、取负、除取模及复合赋值失败写 `stderr` 后 `EXIT_FAILURE`。 |
| 循环安全 | `for` start/end/step 各求值一次；动态 step 在进入循环前必须为正，范围感知推进可正常完成 i32 上界。 |

字符串相等使用内容比较：C 后端生成 `strcmp(left, right) == 0` 或 `!= 0`。返回值函数可在循环体内返回，但函数末尾仍需兜底 `return` 或完整 `if / else if / else` 返回分支。

表达式优先级为算术高于比较，比较高于 `not`，`not` 高于 `and`，`and` 高于 `or`。`and` / `or` 运行时从左到右短路；C 后端递归生成保留 AST 括号的 `!`、`&&`、`||`。

## C 与 LLVM 后端对照

| 维度 | 默认 C 后端 | 实验性 LLVM 文本 IR 后端 |
| --- | --- | --- |
| 选择 | 默认；`--backend c` | `--backend llvm` |
| 覆盖范围 | 完整 v0.37 C 语言路径 | 经共享 checker 静态安全检查的空 `main` 或顶层纯整数 `print` 子集 |
| 不支持 | 无额外后端限制 | 动态值、变量、赋值、比较、布尔、字符串、控制流、用户函数；`LogicalNotExpr` 与 `LogicalExpr` 报明确能力错误 |
| 构建 | 生成 C 后调用 `clang` | 生成 `.ll` 后调用共享 `clang` |

`--backend {c,llvm}` 默认选 `c`。共享 checker 在进入 LLVM lowering 前拒绝纯静态零除和每个 i32 中间溢出，LLVM 不再接受源码层静态回绕；含动态表达式、变量或控制流的程序仍报能力错误。LLVM 只是实验性子集，不能把它当成 v0.37 全量后端。

## 运行与验证

环境通常需要 Python 3.12+、`clang` 在 `Path` 中；Windows 还需要可用的 MSVC/Windows SDK 链接环境。

```powershell
python -m unittest discover -v
python lai_compiler.py main.ly --run
python lai_compiler.py examples/basic_comparisons.ly --run
python lai_compiler.py examples/boolean_logic.ly --run
python lai_compiler.py examples/runtime_integer_safety.ly --run
python lai_compiler.py examples/unary_integer.ly --backend llvm --run
python lai_compiler.py examples/llvm_minimal.ly --backend llvm --run
python lai_compiler.py examples/llvm_arithmetic.ly --backend llvm --run
```

测试覆盖翻译、AST、模块边界、stdlib、clang 和 LLVM 子集。端到端命令既验证生成代码，也验证本机 `clang` 环境。

## 未实现边界

- 布尔逻辑符号别名 `&&` / `||` / `!` 和非 `bool` truthiness 未实现。
- 通用 `return` 早退、`while true { return ... }` 的保证返回分析、赋值表达式和完整运算符优先级未实现。
- 倒序 `for`、负步长、`for item in list`、带标签 `break` / `continue`、`count++` 未实现。
- 浮点数、动态范围分析、运行时错误恢复和动态非正 `step` 的反向循环语义未实现。
- 字符串排序、跨类型相等、隐式转换、默认/命名/可变参数、重载、变量类型标注、GC、JIT、并发未实现。
- 完整 LLVM 后端未实现；合法 `CompareExpr`、`LogicalNotExpr`、`LogicalExpr` 在 LLVM 路径仍会报能力错误。

`step` 仍是保留关键字。下一版是 v0.38 通用函数早退。剩余编号队列为 v0.38-v0.44，共 7 个版本。
