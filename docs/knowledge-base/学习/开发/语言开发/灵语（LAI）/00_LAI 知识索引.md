# LAI（灵语）知识索引

最后同步：2026-07-28

## 当前定位

LAI 是一个极简编程语言原型。当前已完成版本是 **v0.35**：默认路径把 `.ly` 源码编译为 C，再由 `clang` 构建 Windows 可执行文件；同时有受限的实验性文本 LLVM IR 路径。**v0.36 布尔逻辑只有设计，尚未实现。**

主流程：

```text
main.ly -> lexer -> parser -> AST -> semantic/type checker -> C codegen + stdlib helpers -> clang -> build/main.exe
```

## 事实优先级

发生冲突时按下面顺序判断，不能把远期文档当成已实现能力：

1. 当前源码、测试和实际运行结果。
2. `README.md` 与 `docs/ai/active-context.md` 的当前版本和能力边界。
3. `docs/ai/roadmap.md` 的已完成版本与后续编号队列。
4. 当前版本对应的 `docs/superpowers/specs/` 设计和 `docs/superpowers/plans/` 实施记录。
5. `docs/Document/` 的长期愿景，以及历史记录。

## AI 快速入口

1. 要确认“现在能否写某个语法”，先读 `02_当前能力与运行方式.md`，再以 `tests/` 和源码验证。
2. 要定位改动位置，读 `01_项目根目录与模块地图.md` 与 `03_架构与编译流程.md`。
3. 要规划新版本，先读 `04_未来版本规划_v0.36-v0.44.md`，再打开对应设计；新语法必须先由用户确认语法方案。
4. 要准备实施或发布，读 `05_开发约定与文档入口.md`，执行其中的验证和文档同步要求。

## 人工阅读顺序

建议首次接手按 `00 -> 01 -> 02 -> 03 -> 04 -> 05` 阅读：先知道结论和范围，再看文件、可用能力、实现链路、后续计划与工作规范。
