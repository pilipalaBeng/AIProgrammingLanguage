# LAI（灵语）知识索引

最后同步：2026-07-29

## 当前定位

LAI 是一个极简编程语言原型。当前版本是 **v0.38**：默认路径把 `.ly` 源码编译为 C，再由 `clang` 构建 Windows 可执行文件；同时保留受限的实验性文本 LLVM IR 路径。

主流程：

```text
main.ly -> lexer -> parser -> AST -> semantic/type/flow checker -> C codegen + stdlib helpers -> clang -> build/main.exe
```

v0.37 建立的 checked i32 语义继续有效：纯静态零除和中间溢出在编译期诊断，动态 C 整数运算通过私有 helper 检查；`for` 三值只求值一次，并保护动态 step 和 i32 上界推进。

v0.38 在共享 checker 中加入路径级控制流分析，支持 guard clause、分支和循环中的通用函数早退，并在第一条不可达语句处报错。分析结果包含 `fallthrough`、`return`、`break`、`continue`、`diverge`；返回值函数的所有可达路径必须返回，发散路径不能代替返回。仅字面量 `true` 及其嵌套括号可证明静态无限 `while`，普通 `while` 和 `for` 仍保守处理。

`examples/general_early_return.ly` 的 C 运行输出依次是 `-1`、`0`、`1`、`7`、`8`。LLVM 路径在第 1 行拒绝该示例，因为 `FunctionDef` 仍不受支持。v0.38 发布基线为 399 项单元测试通过。

下一版是 v0.39 数组核心；剩余编号队列为 v0.39-v0.44，共 6 个版本。数组仍未实现。

## 事实优先级

发生冲突时按下面顺序判断，不能把远期文档当成已实现能力：

1. 当前源码、测试和实际运行结果。
2. `README.md` 与 `docs/ai/active-context.md` 的当前版本和能力边界。
3. `docs/ai/roadmap.md` 的已完成版本与后续编号队列。
4. 当前版本对应的 `docs/superpowers/specs/` 设计和 `docs/superpowers/plans/` 实施记录。
5. `docs/Document/` 的长期愿景，以及历史记录。

## AI 快速入口

1. 要确认“现在能否写某个语法”，先读 `02_当前能力与运行方式.md`，再以 `tests/` 和源码验证。
2. 要定位改动位置，读 `01_项目根目录与模块地图.md` 与 `03_架构与编译流程.md`。
3. 要规划新版本，先读 `04_未来版本规划_v0.39-v0.44.md`，再打开对应设计；新语法必须先由用户确认语法方案。
4. 要准备实施或发布，读 `05_开发约定与文档入口.md`，执行其中的验证和文档同步要求。
