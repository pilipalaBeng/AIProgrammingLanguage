# LAI 项目根目录与模块地图

历史同步：2026-07-29。本地更新：2026-09-05。本文描述当前 v0.39 仓库布局；模块职责以当前源码为准。本次未访问或上传有道云。

## 源码模块

| 路径 | 职责 |
| --- | --- |
| `lai_compiler.py` | 词法、递归下降解析、文件编译流程和 CLI；表达式解析遵守既定优先级。 |
| `lai_ast.py` | 共享不可变 AST：`Program`、函数、语句和表达式节点。 |
| `lai_core.py` | `LaiCompileError` 与核心名称规则。 |
| `lai_checker.py` | 共享语义、类型和控制流检查；组合 `fallthrough`、`return`、`break`、`continue`、`diverge`，验证所有可达路径返回并定位第一条不可达语句。 |
| `lai_backend.py` | 不可变的通用 `Backend` 描述符。 |
| `lai_clang.py` | C 与 LLVM 路径复用的 `clang` 调用和既有错误措辞。 |
| `lai_c_backend.py` | 完整默认 C 代码生成；动态 i32 运算走 checked runtime helper，`for` 固定三值并范围感知推进。 |
| `lai_llvm_backend.py` | 受限文本 LLVM IR；用户函数、动态值和控制流仍明确不支持。 |
| `lai_stdlib.py` | 内部 C preamble、字符串转义、`print` 输出辅助；不是用户标准库 API。 |
| `lai_int.py` | i32 边界和纯整数静态求值，支持静态零除数、边界和 step 检查。 |
| `lai_types.py` | 不可变 `ArrayType(element_type, length)`、三种数组类型及局部数组目标辅助。 |

v0.39 数组扩展：`lai_ast.py` 新增 `ArrayExpr`、`IndexExpr` 和兼容旧构造的 `LetStmt.type_name`；checker 检查同构元素与静态边界，C 后端用 `CArrayBinding` 记录内部存储名，`lai_stdlib.py` 输出动态索引检查 helper。

## 历史 v0.38 发布基线

v0.38 没有新增语法节点或后端 lowering；核心变化位于共享 checker。guard clause 和路径级早退已支持，返回值函数必须在所有可达路径返回，第一条不可达语句会报错。`while true` 的证明只识别字面量 `true` 及其括号；普通循环保守处理，`diverge` 不算返回。

v0.37 的 checked i32、动态运行时检查、`for` 三值单次求值和 collision-free 内部前缀继续有效。C 示例 `examples/general_early_return.ly` 输出 `-1`、`0`、`1`、`7`、`8`；LLVM 在第 1 行因 `FunctionDef` 不支持而拒绝。发布验证为 399 项单元测试通过。

v0.39 已实现局部数组创建与只读索引，完整 449 项测试及 C/LLVM 示例验证通过。下一版为 v0.40 数组实用操作，剩余 v0.40-v0.45 共 6 版，多维数组仍在 v0.41；跨函数数组和整体复制尚未编号。

## 生成物与历史文件边界

- `build/` 是默认 C 编译生成目录；`build/main.c`、`build/main.exe` 都由编译器写出，不能手工维护或当作源代码。
- `examples/build/*.ll` 与 `examples/build/*.exe` 是 LLVM 示例的本地生成输出，通常未跟踪，不应提交。
- `hello.c`、`hello.exe` 是早期实验文件；没有明确任务时不要在其上扩展功能。
- `.ly` 是推荐源码扩展名；旧 `.lai` 暂可读取，但只作为历史兼容边界。
