# LAI v0.5 源码扩展名设计

日期：2026-07-07

## 目标

v0.5 将 LAI / 灵语的正式源码扩展名从 `.lai` 切换为 `.ly`。

`.ly` 来自“灵语 / LingYu”，比 `.lai` 更短，也避免 `.ai` 这类高冲突扩展名。

## 范围

本版本支持：

- 示例源文件改为 `main.ly`。
- README、路线图、项目记忆和 agent 指南使用 `main.ly`。
- CLI 帮助文本显示 `Path to a .ly source file.`。
- 端到端命令改为 `python lai_compiler.py main.ly --run`。

本版本不做：

- 不禁止旧 `.lai` 文件。编译器仍按普通路径读取输入文件。
- 不引入扩展名强校验。
- 不新增语法、类型系统或运行时能力。

## 兼容策略

`.ly` 是推荐和正式扩展名；`.lai` 暂时作为历史扩展名保留兼容。这样不会破坏旧 scratch
文件或用户临时实验文件。

后续如果需要严格扩展名检查，应单独作为一个小版本处理，并提供迁移提示。

## 测试

新增 CLI 帮助测试：

- `python lai_compiler.py --help` 的帮助文本应包含 `.ly source file`。
- 帮助文本不应再包含 `.lai source file`。
