# LAI v0.21 Through Loop Design

最后更新：2026-07-10

## 目标

v0.21 在已有 `for i from start to end` 基础上，新增包含终点的正向计数循环：

```lai
for i from 0 through 3 {
    print(i)
}
```

语义为包含起点、包含终点。上例输出 `0`、`1`、`2`、`3`。

## 设计取舍

选择新增关键字 `through`，不改变已有 `to` 的语义。

原因：

- `to` 在 v0.18 已明确为不包含终点，不能悄悄改语义。
- `through` 比 `to_inclusive` 或符号范围表达式更适合当前极简英文关键字风格。
- 保持 `for` 结构固定：`for name from start through end [step expr] { ... }`。
- 继续只支持正向循环，避免和负数、倒序条件、溢出、终止性分析混在一起。

## 范围

包括：

- 新增包含终点循环：

  ```lai
  for i from start through end {
      ...
  }
  ```

- 支持和 `step` 组合：

  ```lai
  for i from 0 through 6 step 2 {
      print(i)
  }
  ```

- `start`、`end` 和 `step` 都必须是 `int`。
- 不写 `step` 时默认步长仍是 `1`。
- C 后端输出正向包含终点循环：

  ```c
  for (int i = start; i <= end; i = i + step) {
      ...
  }
  ```

不包括：

- 不支持倒序循环。
- 不支持负数 step。
- 不支持 `for item in list`。
- 不支持范围表达式。
- 不支持普通减法、负数、括号表达式或完整运算符优先级。
- 不做复杂终止性分析。

## 语法规则

```text
for_statement := "for" name "from" expr ("to" | "through") expr ["step" expr] block
```

示例：

```lai
for i from 0 through 3 {
    print(i)
}
```

`through` 是 v0.21 新增关键字，不作为普通变量名使用。

## 语义规则

- `to` 不包含终点，保持旧行为。
- `through` 包含终点。
- 循环变量自动声明为循环体局部 `int`。
- 如果循环变量名已经在当前可见作用域中存在，编译器报重复变量错误。
- `start`、`end` 和显式 `step` 都必须是 `int`。
- `step` 省略时默认是 `1`。
- 显式静态 `step 0` 继续报错。
- 当前不证明动态 step 是否大于 0；只做类型检查。
- `break`、`continue`、嵌套循环和循环体内局部 `return` 沿用已有规则。

## 架构影响

### AST

扩展：

- `ForStmt(name, start, end, statements, line, step=None, inclusive_end=False)`

`inclusive_end=False` 表示 `to`；`inclusive_end=True` 表示 `through`。

### Lexer

新增关键字：

- `through`

### Parser

扩展 `_parse_for_statement(...)`：

- `from expr to expr` 生成 `inclusive_end=False`。
- `from expr through expr` 生成 `inclusive_end=True`。
- 两种边界后都可以继续解析可选 `step expr`。

### Checker

复用现有 `ForStmt` 检查：

- 起点、终点、步长类型仍必须是 `int`。
- 循环变量、作用域、`break` / `continue`、局部 `return` 规则不变。

### C Backend

根据 `inclusive_end` 选择比较符：

```c
// to
i < end

// through
i <= end
```

## 错误行为

需要测试覆盖：

- `for i from 0 through 3` 生成 C `i <= 3`。
- `for i from 0 to 3` 仍生成 C `i < 3`。
- `through` 可与 `step` 组合。
- `through` 终点不是 `int` 时沿用 `for end must be int` 报错。
- `through` 关键字不能作为普通变量名使用。
- `break` / `continue` 和循环体内局部 `return` 在 `through` 循环中继续可用。
