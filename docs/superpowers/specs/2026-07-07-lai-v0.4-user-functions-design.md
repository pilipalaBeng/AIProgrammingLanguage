# LAI v0.4 用户自定义函数设计

日期：2026-07-07

## 目标

v0.4 增加最小用户自定义函数闭环，让 LAI 程序可以把逻辑拆成多个命名块，再从
`main` 中调用。

示例：

```lai
fn greet() {
    print("Hello")
}

fn main() {
    greet()
}
```

## 范围

本版本支持：

- 多个顶层 `fn name() { ... }` 定义。
- 必须存在一个 `fn main() { ... }`。
- 用户函数为零参数、无返回值。
- 函数调用语句：`greet()`。
- 用户函数可以调用其他用户函数。
- C 后端为用户函数生成 `static void name(void)` 和原型声明。

本版本不支持：

- 函数参数。
- 返回值。
- 函数调用作为表达式。
- 重载、闭包、模块系统。
- 用户自定义函数名使用关键字。

## 架构变化

AST 增加：

- `FunctionDef`：记录函数名、函数体语句和定义行号。
- `CallStmt`：记录函数调用语句和行号。
- `Program.functions`：记录除 `main` 外的用户函数列表，保留 `Program.statements`
  作为 `main` 函数体，兼容已有测试中的手写 AST。

Parser 从只解析一个 `fn main` 改为解析多个顶层函数。解析结束时检查 `main` 是否存在，
并拒绝重复函数名。

C codegen 先收集用户函数名，生成用户函数原型，再生成用户函数体，最后生成 `main`。
每个函数都有独立变量符号表。函数调用只允许调用已定义的用户函数。

## 错误行为

- 重复函数名：`function already defined`。
- 调用不存在的函数：`unknown function: <name>`。
- 缺失 `main`：`expected main function` 或原有语法位置错误。

## 测试

新增测试覆盖：

- 从 `main` 调用用户函数。
- 用户函数调用另一个用户函数。
- 重复函数名报错。
- 未知函数调用报错。
