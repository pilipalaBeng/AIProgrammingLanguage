# LAI v0.24 Minus Assignment Design

最后更新：2026-07-10

## 目标

v0.24 新增最小 `-=` 减法赋值语法糖，让用户可以写：

```lai
count -= 1
count -= step_size()
```

语义等价于：

```lai
count = count - value
```

本版本只补齐普通减法之后最自然的复合赋值能力。它不新增 `*=`, `/=`, `count++`, 负数、乘法、除法或完整运算符优先级。

## 范围

包括：

- 在函数体、`if` / `else if` / `else` 分支、`while` 循环和 `for` 循环中使用 `-=`.
- 左侧必须是已有变量或参数。
- 左侧类型必须是 `int`。
- 右侧表达式必须是 `int`。
- 右侧可以使用整数、变量、函数调用、加法、减法和括号表达式。
- C 后端生成 `name = name - value;`。

不包括：

- 不新增 `*=`, `/=`, `count++`。
- 不新增负数或一元负号。
- 不新增乘法、除法或完整运算符优先级。
- 不改变 `+=`、普通赋值或普通减法表达式的语义。

## 语法规则

新增语句：

```text
minus_assign_stmt := name "-=" expr
```

示例：

```lai
fn main() {
    let count = 5
    count -= 2
    print(count)
}
```

## 语义规则

- `name -= expr` 要求 `name` 已经存在。
- `name` 的类型必须是 `int`。
- `expr` 的类型必须是 `int`。
- `name -= expr` 不改变 `name` 的类型。
- 未知变量报 `unknown variable: name`。
- 非 `int` 左侧报 `cannot use -= with name of type string` 或对应实际类型。
- 非 `int` 右侧报 `-= value must be int, got bool` 或对应实际类型。

## 架构影响

### AST

新增：

- `MinusAssignStmt(name: str, value: Expr, line: int)`

它和 `PlusAssignStmt` 对称，表示一个语句节点。

### Parser

- lexer 已经有 `MINUS_EQUAL` token。
- `_parse_statement(...)` 在识别 `MINUS_EQUAL` 时返回 `MinusAssignStmt(...)`。
- 不再把 `-=` 当作 unsupported assignment operator。

### Checker

`_check_statement(MinusAssignStmt(...))`：

1. 校验变量名。
2. 校验变量存在。
3. 校验变量类型是 `int`。
4. 推断右侧表达式类型。
5. 校验右侧类型是 `int`。

### C Backend

`_statement_to_c(MinusAssignStmt(...))` 生成：

```c
name = name - value;
```

## 测试要求

覆盖：

- tokenizer 识别 `MINUS_EQUAL`。
- `count -= 1` 生成 `count = count - 1;`。
- 右侧可以是 `int` 表达式，例如 `count -= add(1, 2)` 和 `count -= (5 - 2)`。
- 函数参数可以使用 `-=`.
- 循环内可以使用 `-=`.
- parser 生成 `MinusAssignStmt`。
- 未知变量使用 `-=` 报错。
- 非 `int` 左侧使用 `-=` 报错。
- 非 `int` 右侧使用 `-=` 报错。
- `+=` 和普通减法表达式现有行为不变。
