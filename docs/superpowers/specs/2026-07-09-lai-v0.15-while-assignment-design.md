# LAI v0.15 While And Assignment Design

最后更新：2026-07-09

## 目标

v0.15 增加最小可用循环闭环：支持 `while condition { ... }`，并同时支持给已有变量重新赋值，例如 `count = count + 1`。

示例：

```lai
fn main() {
    let count = 0
    while count < 3 {
        print(count)
        count = count + 1
    }
}
```

## 范围

包括：

- 新增 `while` 关键字。
- 新增 `WhileStmt` AST 节点。
- 新增 `AssignStmt` AST 节点，用于 `name = expr`。
- `while` 条件必须是 `bool`。
- 赋值目标必须是已存在变量或参数。
- 赋值表达式类型必须和原变量类型一致。
- C 后端生成 `while (...) { ... }` 和普通赋值语句。

不包括：

- 不支持 `for`。
- 不支持 `break` / `continue`。
- 不支持自增语法 `count++`、复合赋值 `count += 1`。
- 不支持循环中的完整 `return` 控制流分析。
- 不支持块内变量泄漏到循环外。
- 不新增括号表达式或完整运算符优先级。

## 语法

### while

```lai
while condition {
    statement
}
```

`condition` 复用现有表达式解析能力，因此可以写：

- `while ready { ... }`
- `while count < 3 { ... }`
- `while is_ready(count) { ... }`

### assignment

```lai
name = expr
```

赋值不是声明。变量必须已经通过 `let` 或函数参数存在。

```lai
let count = 0
count = count + 1
```

## 语义规则

- `while` 条件必须推断为 `bool`，否则报错。
- `while` 体使用符号表副本检查，因此循环体内 `let` 的变量不会泄漏到循环外。
- `AssignStmt` 只改变已有名字的值，不改变名字类型。
- 对未知变量赋值时报错。
- 对变量赋不同类型的值时报错。
- 无返回值函数和 `main` 中，循环体内仍禁止 `return`。
- 返回值函数中，循环不能作为“保证返回”的最终路径；v0.15 不做循环返回分析。

## 架构影响

### AST

新增：

- `AssignStmt(name: str, value: Expr, line: int)`
- `WhileStmt(condition: Expr, statements: list[Stmt], line: int)`

### Parser

修改 `lai_compiler.py`：

- `_KEYWORDS` 新增 `while`。
- `_parse_statement` 新增 `while` 语句解析。
- `_parse_statement` 新增 `name = expr` 赋值解析。

赋值需要在普通函数调用语句附近处理：

- `name(...)` -> `CallStmt`
- `name = expr` -> `AssignStmt`

### Checker

修改 `lai_checker.py`：

- `AssignStmt`：检查目标存在、推断右侧类型、比较目标原类型。
- `WhileStmt`：检查条件为 `bool`，再用符号表副本检查循环体。
- 返回控制流分析继续拒绝循环作为保证返回路径。

### C Backend

修改 `lai_c_backend.py`：

- `AssignStmt` 生成 `name = value;`
- `WhileStmt` 生成：

```c
while (condition) {
    ...
}
```

## 错误行为

新增或复用错误：

- `line N: while condition must be bool, got int`
- `line N: unknown variable: name`
- `line N: cannot assign string to count of type int`

## 测试

新增测试覆盖：

- `while count < 3 { ... }` 生成 C `while`。
- 循环体内赋值 `count = count + 1`。
- 参数可以被重新赋值。
- `while` 条件不是 `bool` 时拒绝。
- 对未知变量赋值时拒绝。
- 赋值类型不匹配时拒绝。
- 循环体内 `let` 变量不泄漏到循环外。
- 循环体内 `return` 在无返回值函数中继续拒绝。
- 返回值函数不能只靠 `while` 作为最终返回路径。
