# LAI v0.13 Function Returns 设计

最后更新：2026-07-08

## 背景

v0.12 已支持用户函数参数，但函数仍然只能作为语句调用，不能返回值。
v0.13 在此基础上补齐最小返回值闭环，让用户函数可以计算 `string`、`int`、`bool`
三种基础类型的结果，并在调用处作为表达式使用。

## 目标

- 支持显式返回类型：`fn add(a: int, b: int) -> int { ... }`。
- 支持 `return expr` 语句。
- 支持函数调用表达式：`let count = add(1, 2)`、`print(add(1, 2))`。
- 支持返回值函数用于 `return`、`let`、`print`、函数调用实参和 `if` 条件。
- 继续支持无返回值函数：`fn greet() { ... }`。
- C 后端生成带返回类型的 `static` 函数声明、定义和调用表达式。

## 非目标

- 不支持 `main` 返回类型，入口仍然是 `fn main() { ... }`。
- 不支持 `return` 出现在无返回值函数或 `main` 中。
- 不支持早退；v0.13 要求带返回值函数的最后一条顶层语句必须是 `return expr`。
- 不支持 `return` 写在 `if` 分支中作为完整控制流分析。
- 不支持递归专门规则、函数重载、默认参数、命名参数或可变参数。
- 不新增完整运算符优先级系统；仅把现有整数加法扩展到可使用整数变量和返回 `int` 的调用表达式。

## 用户语法

```lai
fn add(a: int, b: int) -> int {
    return a + b
}

fn label() -> string {
    return "ready"
}

fn is_ready(count: int) -> bool {
    return count == 3
}

fn main() {
    let count = add(1, 2)
    print(count)
    print(label())
    if is_ready(count) {
        print("ok")
    }
}
```

无返回值函数保持原语法：

```lai
fn greet(name: string) {
    print(name)
}
```

## AST

新增语句和表达式节点：

```python
@dataclass(frozen=True)
class ReturnStmt(Stmt):
    value: Expr
    line: int

@dataclass(frozen=True)
class CallExpr(Expr):
    name: str
    args: list[Expr] | None
    line: int
```

扩展：

- `FunctionDef.return_type: str | None = None`

默认值用于保持旧测试和手写 AST 的兼容性。

## Parser

- 新增 `return` 关键字。
- 新增 `->` token，必须写在参数列表之后、函数体 `{` 之前。
- 函数返回类型格式为 `-> type`，类型名先由 parser 记录，是否合法交给 checker。
- `main` 不能带返回类型。
- 表达式解析增加调用表达式：`add(1, 2)`。
- 整数加法从仅支持整数字面量扩展为支持整数表达式项，例如 `a + b`、`add(1, 2) + 3`。

## Checker

checker 维护函数签名：

- 参数类型列表。
- 返回类型，`None` 表示无返回值函数。

检查规则：

- 返回类型必须是 `string`、`int` 或 `bool`。
- 无返回值函数中不能出现 `return`。
- 带返回值函数最后一条顶层语句必须是 `return expr`。
- `return expr` 的表达式类型必须匹配函数返回类型。
- 调用无返回值函数不能作为表达式使用。
- 函数调用表达式继续检查实参数量和实参类型。

## C Backend

返回类型映射：

- `string` -> `const char*`
- `int` -> `int`
- `bool` -> `int`
- 无返回值 -> `void`

示例输出：

```c
static int add(int a, int b);

static int add(int a, int b) {
    return a + b;
}
```

## 验收

- 单元测试覆盖 `int`、`string`、`bool` 返回值。
- 单元测试覆盖函数调用表达式用于 `let`、`print`、`return`、实参和 `if` 条件。
- 单元测试覆盖返回类型非法、缺失最终 `return`、返回类型不匹配。
- 单元测试覆盖无返回值函数不能 `return`，无返回值调用不能作为表达式。
- 单元测试覆盖调用表达式的实参数量和类型错误。
- `python -m unittest discover -v` 通过。
- `python lai_compiler.py main.ly --run` 通过，并输出返回值 demo 内容。
