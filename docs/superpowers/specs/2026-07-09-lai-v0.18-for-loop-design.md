# LAI v0.18 For Loop Design

最后更新：2026-07-09

## 目标

v0.18 新增一个 AI 友好的最小计数循环：

```lai
for i from 0 to 3 {
    print(i)
}
```

语义固定为：从起点开始，逐次加 `1`，直到到达终点前停止。也就是包含起点、不包含终点，所以上例输出 `0`、`1`、`2`。

## 设计取舍

选择 `for i from 0 to 3`，而不是 C 风格 `for let i = 0; i < 3; i = i + 1`。

原因：

- 结构固定，AI 更容易生成正确代码。
- 起点和终点语义清楚，不把初始化、条件和更新混在一起。
- 可以直接编译到 C 的 `for`，保持当前后端简单。
- 暂时不引入范围表达式、迭代器、集合遍历或 `step`。

`to` 的边界规则在 v0.18 中明确为“不包含终点”。以后如果需要包含终点，可以另设计 `through` 或其他显式语法，不复用 `to` 改语义。

## 范围

包括：

- 新增 `for` 语句：

  ```lai
  for i from start to end {
      ...
  }
  ```

- `i` 是循环局部 `int` 变量。
- `start` 和 `end` 必须是 `int` 表达式。
- 循环变量只在循环体内可见，不泄漏到循环外。
- 循环体内允许 `break`、`continue`、`if`、`while`、嵌套 `for` 和已有语句。
- 返回值函数中的 `for` 循环体内允许局部 `return`，但 `for` 本身不算保证返回路径。
- C 后端输出简单可读的 `for (int i = start; i < end; i = i + 1)`。

不包括：

- 不支持 `step`。
- 不支持倒序循环。
- 不支持包含终点的循环。
- 不支持 `for item in list`。
- 不支持范围表达式 `0..3`。
- 不支持循环变量类型声明。
- 不做复杂不可达代码分析。

## 语法规则

```text
for_statement := "for" name "from" expr "to" expr block
```

示例：

```lai
for i from 0 to 3 {
    print(i)
}
```

`for`、`from`、`to` 是 v0.18 的语法关键字。循环变量名仍使用当前名称规则。

## 语义规则

- 循环变量自动声明为 `int`。
- 如果循环变量名已经在当前可见作用域中存在，编译器报重复变量错误。
- `start` 和 `end` 都必须是 `int`。
- 每轮循环结束后，循环变量自动加 `1`。
- 如果 `start >= end`，循环体执行 `0` 次。
- `break` 跳出最近一层循环，`continue` 进入最近一层循环的下一轮。
- 循环体使用符号表副本；循环内 `let` 的变量和循环变量不会泄漏到外层。

## 架构影响

### AST

新增：

- `ForStmt(name, start, end, statements, line)`

### Lexer

新增关键字：

- `for`
- `from`
- `to`

### Parser

新增 `_parse_for_statement(...)`，在 `_parse_statement(...)` 中识别 `FOR`。

### Checker

新增 `ForStmt` 检查：

- 校验循环变量名。
- 校验循环变量不与当前符号表冲突。
- 校验 `start` 和 `end` 是 `int`。
- 给循环体符号表副本加入 `name: int`。
- 用 `loop_depth + 1` 检查循环体，使 `break` / `continue` 在 `for` 内合法。
- 返回值函数中的 `for` 按 v0.17 的循环局部 `return` 规则处理。

### C Backend

生成：

```c
for (int i = start; i < end; i = i + 1) {
    ...
}
```

## 错误行为

需要测试覆盖：

- `for i from 0 to 3` 生成 C `for`。
- `for` 循环变量不泄漏到循环外。
- `start` 不是 `int` 时报错。
- `end` 不是 `int` 时报错。
- 循环变量重复已有变量时报错。
- `break` / `continue` 在 `for` 内合法。
- 返回值函数中 `for` 内局部 `return` 合法，但最终 `for` 仍不算保证返回。
