# LAI v0.23 Subtraction Expressions Design

最后更新：2026-07-10

## 目标

v0.23 新增普通二元减法表达式，让用户可以写：

```lai
let count = 5 - 2
print(count - 1)
return a - b
```

本版本只补齐最小整数减法能力。它不新增 `-=`, 负数、乘法、除法或完整运算符优先级。

## 范围

包括：

- 在 `let`、`print`、`return`、函数实参、赋值、`+=` 右侧、`if` / `while` 条件里的比较表达式、`for` 起点/终点/步长表达式中使用减法。
- 支持变量、整数、函数调用、括号表达式参与减法。
- 支持左结合的连续减法，例如 `10 - 3 - 2` 等价于 `(10 - 3) - 2`。
- 支持与加法在同一层组合，例如 `10 + 3 - 2` 和 `10 - 3 + 2`。
- C 后端生成可读 C 表达式，例如 `count - 1`。
- checker 要求减法左右两侧都是 `int`。

不包括：

- 不新增 `-=`。
- 不新增负数或一元负号，例如 `-1`。
- 不新增乘法、除法或完整运算符优先级。
- 不改变比较表达式仍只接受 `int` 操作数的规则。
- 不改变 `+` 的现有行为。

## 语法规则

把当前加法层扩展为加减同层、左结合：

```text
expr        := additive_expr (("<" | ">" | "==") additive_expr)?
additive    := primary (("+" | "-") primary)*
primary     := string | true | false | int | name | call_expr | "(" expr ")"
```

示例：

```lai
let a = 10 - 3
let b = (a + 2) - 1
let ok = (10 - 3) == 7
```

## 语义规则

- `left - right` 的结果类型是 `int`。
- 左右两侧都必须是 `int`。
- `1 - "x"` 报 `subtraction operands must both be int, got int and string`。
- `"x" - 1` 报 `subtraction operands must both be int, got string and int`。
- `print(-1)` 仍然不支持，报 `expected expression` 或等价语法错误。
- `count -= 1` 仍然不支持；当前应保持拒绝。

## 架构影响

### AST

新增：

- `SubtractExpr(left: Expr, right: Expr)`

`AddExpr` 继续保留现有 n-ary 结构。混合加减表达式可以由 `AddExpr` 和 `SubtractExpr` 组合表示。

### Parser

- lexer 新增 `-` token：`MINUS`。
- tokenizer 继续优先识别 `->`，避免返回类型箭头被拆成 `MINUS` 和 `GT`。
- `_parse_add_expr(...)` 扩展为同层处理 `PLUS` 和 `MINUS`。
- `-` 后必须跟 primary expression；不把 `-1` 当作整数。

### Checker

`_infer_expr_type(SubtractExpr(...))`：

1. 推断左右类型。
2. 如果有任一侧不是 `int`，抛 `LaiCompileError`。
3. 返回 `int`。

### C Backend

`_expr_to_c_value(SubtractExpr(...))`：

1. 转换左右表达式。
2. 校验左右类型是 `int`。
3. 返回 `("int", f"{left} - {right}")`。

## 测试要求

覆盖：

- `print(5 - 2)` 生成 `printf("%d\n", 5 - 2);`。
- `let count = 5 - 2` 生成 `int count = 5 - 2;`。
- `return a - b` 生成 `return a - b;`。
- 函数实参支持减法，例如 `show(5 - 2)`。
- 比较表达式支持减法，例如 `let ok = (5 - 2) == 3`。
- 括号和加法组合支持，例如 `print((5 + 2) - 1)`。
- AST 中能看到 `SubtractExpr`。
- `1 - "x"` 报减法类型错误。
- `print(1 -)` 报 `expected expression`。
- `print(-1)` 不作为负数字面量被接受。
- `count -= 1` 仍然不支持。
