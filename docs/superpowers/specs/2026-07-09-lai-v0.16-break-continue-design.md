# LAI v0.16 Break And Continue Design

最后更新：2026-07-09

## 目标

v0.16 在 v0.15 的最小 `while` 循环基础上，补齐两个最常用的循环控制语句：

```lai
break
continue
```

示例：

```lai
fn main() {
    let count = 0
    while count < 5 {
        count = count + 1
        if count < 2 {
            continue
        }
        print(count)
        if count > 2 {
            break
        }
    }
}
```

## 范围

包括：

- 新增 `break` 关键字。
- 新增 `continue` 关键字。
- 新增 `BreakStmt` AST 节点。
- 新增 `ContinueStmt` AST 节点。
- `break` 只能出现在循环体内部。
- `continue` 只能出现在循环体内部。
- `break` / `continue` 可以出现在循环体内嵌套的 `if / else if / else` 分支里。
- C 后端生成 `break;` 和 `continue;`。

不包括：

- 不支持带标签的 `break label` 或 `continue label`。
- 不支持多层指定跳出。
- 不支持 `for`。
- 不改变循环中的 `return` 控制流分析。
- 不新增 `+=`、`++` 或其他赋值语法糖。

## 语法

### break

```lai
break
```

只能作为独立语句出现。

### continue

```lai
continue
```

只能作为独立语句出现。

## 语义规则

- `break` 必须位于某个 `while` 循环体内部。
- `continue` 必须位于某个 `while` 循环体内部。
- 如果 `break` 或 `continue` 出现在循环外，编译器报错。
- 如果 `break` 或 `continue` 出现在循环体里的 `if` 分支中，仍然合法。
- v0.16 不把 `break` / `continue` 纳入返回值函数的完整返回路径分析。

## 架构影响

### AST

新增：

- `BreakStmt(line: int)`
- `ContinueStmt(line: int)`

### Parser

修改 `lai_compiler.py`：

- `_KEYWORDS` 新增 `break` 和 `continue`。
- `_parse_statement` 新增 `BREAK` 和 `CONTINUE` 分支。
- `lai_compiler.py` 继续兼容导出新增 AST 节点。

### Checker

修改 `lai_checker.py`：

- `_check_statements` 和 `_check_statement` 增加 `loop_depth` 参数。
- 进入 `WhileStmt` 体时，`loop_depth + 1`。
- 检查 `IfStmt` 分支时，沿用当前 `loop_depth`。
- 遇到 `BreakStmt` / `ContinueStmt` 时，如果 `loop_depth <= 0` 则报错。

建议错误信息：

- `line N: break is only allowed inside while loop`
- `line N: continue is only allowed inside while loop`

### C Backend

修改 `lai_c_backend.py`：

- `BreakStmt` 生成 `break;`
- `ContinueStmt` 生成 `continue;`

## 测试

新增测试覆盖：

- `while` 体内生成 `break;`。
- `while` 体内生成 `continue;`。
- `break` / `continue` 可以放在循环体内的 `if` 中。
- parser 会生成 `BreakStmt` / `ContinueStmt`。
- `lai_compiler.py`、`lai_checker.py`、`lai_c_backend.py` 兼容导出或导入新增节点。
- 顶层 `break` 报错。
- 顶层 `continue` 报错。
- 非循环内 `if` 分支里的 `break` 报错。
