# LAI v0.20 For Step Design

最后更新：2026-07-10

## 目标

v0.20 在已有最小计数 `for` 循环上新增正向步长：

```lai
for i from 0 to 10 step 2 {
    print(i)
}
```

语义保持为包含起点、不包含终点。上例输出 `0`、`2`、`4`、`6`、`8`。

## 设计取舍

选择在现有 `for i from start to end` 后追加可选 `step expr`，而不是改成 C 风格三段式。

原因：

- 保持 `for` 结构固定，AI 生成代码时更稳定。
- 不改变 v0.18 的默认步长；不写 `step` 时仍然每轮加 `1`。
- `step` 和 `to` 一样是显式关键词，读起来接近自然语言。
- 暂时只支持正向循环，避免同时设计倒序条件、包含终点边界和负数语法。

## 范围

包括：

- 新增可选 `step`：

  ```lai
  for i from start to end step step_value {
      ...
  }
  ```

- `start`、`end` 和 `step_value` 都必须是 `int` 表达式。
- 不写 `step` 时，行为继续等价于 `step 1`。
- 仍使用 `to` 不包含终点。
- C 后端输出简单可读的正向循环：

  ```c
  for (int i = start; i < end; i = i + step_value) {
      ...
  }
  ```

不包括：

- 不支持倒序循环。
- 不支持负数 step。
- 不支持包含终点循环。
- 不支持 `for item in list`。
- 不支持范围表达式。
- 不支持普通减法、负数、括号表达式或完整运算符优先级。
- 不做通用常量折叠或复杂终止性分析。

## 语法规则

```text
for_statement := "for" name "from" expr "to" expr ["step" expr] block
```

示例：

```lai
for i from 0 to 6 step 2 {
    print(i)
}
```

`step` 是 v0.20 新增关键字，不作为普通变量名使用。

## 语义规则

- 循环变量自动声明为循环体局部 `int`。
- 如果循环变量名已经在当前可见作用域中存在，编译器报重复变量错误。
- `start`、`end` 和 `step` 都必须是 `int`。
- `step` 省略时默认是 `1`。
- `step` 为显式字面量 `0` 时直接报错，避免明显死循环。
- 当前不做通用动态正数证明；如果 `step` 来自变量或函数调用，编译器只做 `int` 类型检查。
- 每轮循环结束后，循环变量自动加上 `step`。
- 如果 `start >= end`，循环体执行 `0` 次。
- `break` 跳出最近一层循环，`continue` 进入最近一层循环的下一轮。
- 循环体使用符号表副本；循环内 `let` 的变量和循环变量不会泄漏到外层。

## 架构影响

### AST

扩展：

- `ForStmt(name, start, end, statements, line, step=None)`

`step=None` 表示没有显式 `step`，后端按 `1` 处理。

### Lexer

新增关键字：

- `step`

### Parser

扩展 `_parse_for_statement(...)`：

- 解析 `to expr` 后，如果看到 `STEP`，继续解析一个 `int` 表达式作为 `step`。
- 没有 `STEP` 时保持现有 AST 兼容。

### Checker

扩展 `ForStmt` 检查：

- 校验 `step` 表达式类型为 `int`。
- 拒绝显式静态 `0` step。
- 其他循环变量、作用域、`break` / `continue`、循环体内局部 `return` 规则保持不变。

### C Backend

无显式 `step` 时继续生成：

```c
for (int i = start; i < end; i = i + 1) {
    ...
}
```

有显式 `step` 时生成：

```c
for (int i = start; i < end; i = i + step_value) {
    ...
}
```

## 错误行为

需要测试覆盖：

- `for i from 0 to 6 step 2` 生成 C `i = i + 2`。
- 不写 `step` 的旧 `for` 继续生成 `i = i + 1`。
- `step` 可以使用 `int` 变量或函数调用表达式。
- `step` 不是 `int` 时报错。
- `step 0` 时报错。
- `step` 关键字不能作为普通变量名使用。
- `break` / `continue` 和循环体内局部 `return` 在 `for step` 中继续可用。
