# LAI v0.7 小型标准库边界设计

日期：2026-07-08

## 目标

v0.7 为 LAI / 灵语建立一个很小的内部标准库/运行时辅助边界。

本版本不新增用户可调用的标准库函数，而是先把 C 后端里和运行时输出相关的细节集中到 `lai_stdlib.py`。

## 范围

本版本支持：

- 新增 `lai_stdlib.py`。
- `c_preamble()` 统一生成 C preamble，例如 `#include <stdio.h>`。
- `escape_c_string()` 统一处理 C 字符串字面量转义。
- `c_print_string_literal()` 统一生成字符串字面量的 `printf`。
- `c_print_value()` 统一根据 `string`、`int`、`bool` 生成变量或表达式的 `printf`。
- `lai_compiler.py` 的 C codegen 调用这些 helper，而不是直接拼接全部输出细节。

本版本不做：

- 不新增 LAI 表面语法。
- 不新增用户可调用标准库函数。
- 不改 `print(...)` 的用户写法。
- 不拆分 lexer、parser、checker 或完整 C backend。
- 不引入外部 Python 依赖。

## 设计说明

`lai_stdlib.py` 目前更像“运行时 C 输出辅助模块”，不是完整标准库。

这样命名是为了给后续能力留位置：未来如果需要 runtime helper、内置函数、字符串辅助函数或平台相关 C 片段，可以先进入这个模块，再决定是否暴露成用户语法。

`lai_compiler.py` 仍然负责解析、检查和整体 C 代码生成。它只把底层 C preamble、字符串转义和 `printf` 格式委托给 `lai_stdlib.py`。

## 兼容性

v0.7 不改变已有合法 `.ly` 程序的行为。

示例程序的输出应保持：

```text
Hello LAI
JD
Hello from function
3
count is three
math works
```

## 测试

新增 `tests/test_lai_stdlib.py`，覆盖：

- C preamble。
- C 字符串转义。
- 字符串字面量打印。
- `string`、`int`、`bool` 打印格式。
- 未知可打印类型报错。

同时保留原有编译器测试和端到端验证。
