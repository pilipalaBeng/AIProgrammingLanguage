# LAI v0.12 Function Parameters 设计

最后更新：2026-07-08

## 背景

v0.4 已支持零参数、无返回值的用户函数，v0.6 以后已有基础类型检查，v0.9 已将 AST 拆到 `lai_ast.py`。
v0.12 在此基础上补齐函数参数，让用户函数可以接收 `string`、`int`、`bool` 三种基础类型的实参。

## 目标

- 支持函数参数声明：`fn greet(name: string) { ... }`。
- 支持多个参数：`fn show(name: string, count: int, ready: bool) { ... }`。
- 支持调用时传实参：`greet("JD")`、`show("JD", 3, true)`。
- 参数可在函数体内像局部变量一样读取。
- 检查参数名重复、参数类型非法、实参数量不匹配、实参类型不匹配。
- C 后端生成带参数的 `static void` 函数声明和定义。

## 非目标

- 不支持返回值。
- 不支持 `return`。
- 不支持函数调用表达式，例如 `let x = add(1, 2)`。
- 不支持默认参数、命名参数、可变参数或函数重载。
- 不允许 `main` 带参数，入口仍然是 `fn main() { ... }`。

## 用户语法

```lai
fn greet(name: string) {
    print(name)
}

fn show_count(count: int) {
    print(count)
}

fn main() {
    greet("JD")
    show_count(123)
}
```

多个参数：

```lai
fn show(name: string, count: int, ready: bool) {
    print(name)
    print(count)
    print(ready)
}

fn main() {
    show("JD", 3, true)
}
```

## AST

新增参数节点：

```python
@dataclass(frozen=True)
class Param:
    name: str
    type_name: str
    line: int
```

扩展：

- `FunctionDef.params: list[Param] | None = None`
- `CallStmt.args: list[Expr] | None = None`

默认值用于保持旧测试和手写 AST 的兼容性。

## Parser

- 新增 `:` 和 `,` token。
- 函数定义参数格式为 `name: type`，多个参数用 `,` 分隔。
- 函数调用参数复用当前表达式解析能力，支持字符串、整数、布尔、变量、比较和整数加法。
- parser 不在语法层判断类型名是否合法；checker 统一报语义错误。

## Checker

checker 维护函数签名：

- 函数名。
- 参数类型列表。
- 参数名列表。

检查规则：

- 参数类型必须是 `string`、`int` 或 `bool`。
- 同一函数内参数名不能重复。
- 函数体符号表初始包含参数。
- `let` 不能重复定义同名参数。
- 调用实参数量必须匹配形参数量。
- 调用实参类型必须匹配形参类型。

## C Backend

参数类型映射：

- `string` -> `const char*`
- `int` -> `int`
- `bool` -> `int`

示例输出：

```c
static void greet(const char* name);

static void greet(const char* name) {
    printf("%s\n", name);
}
```

## 验收

- 单元测试覆盖单参数和多参数函数生成 C。
- 单元测试覆盖参数在函数体内可读取。
- 单元测试覆盖参数数量不匹配。
- 单元测试覆盖参数类型不匹配。
- 单元测试覆盖重复参数名和非法参数类型。
- 单元测试覆盖 `main` 不能带参数。
- `python -m unittest discover -v` 通过。
- `python lai_compiler.py main.ly --run` 通过，并输出参数 demo 内容。
