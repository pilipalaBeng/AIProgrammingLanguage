# LAI v0.14 Branch Return Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow returning LAI functions to end with full `if / else if / else` return paths.

**Architecture:** Reuse the existing `ReturnStmt` and `IfStmt` AST nodes. Keep parser and C backend mostly unchanged; implement recursive return-path validation in `lai_checker.py`. Update sample and docs after tests pass.

**Tech Stack:** Python 3.12+, `unittest`, current LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Keep `fn main()` parameterless and returnless.
- Do not add loops, `break`, `continue`, general early return, or parentheses.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C readable and compatible with the current C backend.

- [x] **Step 1: Add return block checker**

Implement helper logic in `lai_checker.py`:

```python
def _check_returning_statements(statements, symbols, function_signatures, expected_return_type, function_line, function_name):
    if not statements:
        raise LaiCompileError(f"line {function_line}: function {function_name} must end with return")
    for statement in statements[:-1]:
        _check_non_returning_statement(statement, symbols, function_signatures, expected_return_type)
    _check_final_returning_statement(statements[-1], symbols, function_signatures, expected_return_type, function_line, function_name)
```

- [x] **Step 2: Reject early returns in the same block**

When a non-final statement contains a `ReturnStmt`, raise:

```text
line N: return must be the final statement in its block
```

- [x] **Step 3: Accept final `ReturnStmt` and final full-return `IfStmt`**

For final `ReturnStmt`, call `_check_return_statement`.

For final `IfStmt`, check the condition is `bool`, then recursively require both branches to return.

- [x] **Step 4: Preserve void-function behavior**

Leave the existing no-return checker path in place so no-return-value functions and `main` still reject nested `ReturnStmt`.
