# LAI v0.24 Minus Assignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `-=` assignment sugar for existing `int` variables and parameters.

**Architecture:** Add `MinusAssignStmt` beside `PlusAssignStmt`. Reuse the existing `MINUS_EQUAL` token, parse it into an AST node, validate int target/value in the checker, and emit `name = name - value;` in the C backend.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Add `-=` assignment sugar only.
- Do not add `*=`, `/=`, `count++`, negative integers, unary minus, multiplication, division, or full operator precedence.
- Do not change existing `+=`, ordinary `-`, `+`, comparison, `to`, `through`, or `step` behavior.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C simple and readable.

```python
if isinstance(statement, MinusAssignStmt):
    if not NAME_RE.match(statement.name):
        raise LaiCompileError(
            f"line {statement.line}: invalid variable name: {statement.name}"
        )
    if statement.name not in symbols:
        raise LaiCompileError(f"line {statement.line}: unknown variable: {statement.name}")
    expected_type = symbols[statement.name]
    if expected_type != "int":
        raise LaiCompileError(
            f"line {statement.line}: cannot use -= with {statement.name} "
            f"of type {expected_type}"
        )
    actual_type = _infer_expr_type(
        statement.value, symbols, statement.line, function_signatures
    )
    if actual_type != "int":
        raise LaiCompileError(
            f"line {statement.line}: -= value must be int, got {actual_type}"
        )
    return
```

- [x] **Step 5: Generate `-=` C**

In `_statement_to_c(...)`, add:

```python
if isinstance(statement, MinusAssignStmt):
    if statement.name not in symbols:
        raise LaiCompileError(f"line {statement.line}: unknown variable: {statement.name}")
    expected_kind = symbols[statement.name]
    if expected_kind != "int":
        raise LaiCompileError(
            f"line {statement.line}: cannot use -= with {statement.name} "
            f"of type {expected_kind}"
        )
    value_kind, c_value = _expr_to_c_value(
        statement.value, symbols, statement.line, function_signatures or {}
    )
    if value_kind != "int":
        raise LaiCompileError(
            f"line {statement.line}: -= value must be int, got {value_kind}"
        )
    return [f"{indent}{statement.name} = {statement.name} - {c_value};"]
```
