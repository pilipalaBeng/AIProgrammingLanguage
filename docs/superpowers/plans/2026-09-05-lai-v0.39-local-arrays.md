# LAI v0.39 Local Arrays Implementation Plan

> **For agentic workers:** Use subagent-driven-development or executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 实现已确认的显式类型局部固定长度数组及安全索引读取。

**Architecture:** AST/parser 负责数组源码结构，checker 记录元素类型和字面量长度，C backend 使用独立的局部连续存储和 checked index helper。数组暂不跨函数流转。

**Tech Stack:** Python 标准库、unittest、C、clang、实验性文本 LLVM IR。

## Global Constraints

- `int[]`、`string[]`、`bool[]` 必须显式声明；数组固定长度，空数组合法。
- 元素严格同类型，初始化表达式按源码顺序各执行一次。
- `array[index]` 使用 `int` 零基索引，负数和 `index >= length` 报错。
- 静态越界编译失败；动态越界输出行号、索引、长度并失败退出；保持逻辑短路。
- 不加入数组写入、复制、参数、返回、比较、整体打印、多维或动态列表。
- 保持旧 AST 构造兼容、默认 C 后端和 LLVM 能力边界。
- 使用现有模块边界，生成物不提交；不访问外部知识库。

## Task 3: C 存储和运行时边界

Files: `lai_c_backend.py`、`lai_stdlib.py`、`tests/test_lai_array_runtime.py`、`examples/local_arrays.ly`。

Interfaces: 内部 `CArrayBinding(array_type: ArrayType, storage_name: str)`；`c_array_runtime_support(prefix) -> list[str]`，helper 名由本轮 collision-free prefix 提供。

```c
static int checked_index(int index, int length, int line) {
    if (index < 0 || index >= length) {
        fprintf(stderr, "LAI runtime error: line %d: array index out of bounds: index %d, length %d\n",
                line, index, length);
        exit(EXIT_FAILURE);
    }
    return index;
}
```
