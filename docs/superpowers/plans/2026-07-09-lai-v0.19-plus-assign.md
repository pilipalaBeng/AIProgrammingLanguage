# LAI v0.19 Plus Assignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the minimal `+=` assignment sugar for existing integer variables.

**Architecture:** Add `PlusAssignStmt` to the shared AST, teach the lexer/parser to recognize `+=`, extend checker validation to require an existing `int` target and `int` value, and emit readable C as `name = name + value;`. Keep existing assignment and integer addition behavior unchanged.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Only add `+=`; do not add `-=`, `*=`, `/=`, `++`, `--`, ordinary subtraction, negative integers, parentheses, or operator precedence.
- `name += expr` is equivalent to `name = name + expr`.
- The target of `+=` must be an existing `int` variable or parameter.
- The right-hand expression of `+=` must be `int`.
- Do not add new Python dependencies.
- Write failing tests before production changes.
