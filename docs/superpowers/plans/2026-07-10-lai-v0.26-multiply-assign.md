# LAI v0.26 Multiply Assignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add minimal integer `*=` assignment sugar.

**Architecture:** Add `MultiplyAssignStmt` beside existing compound assignment
nodes. Tokenize `*=` as `STAR_EQUAL`, parse it as a statement, validate the
target and value as `int`, and lower to explicit C assignment
`name = name * value;`.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C
backend, local `clang`.

## Global Constraints

- Add `*=` statements only.
- Reuse existing `+=` and `-=` behavior and error style.
- Do not add `/`, `/=`, `%`, `%=`, `count++`, negative integers, unary minus,
  string repetition, assignment expressions, or full operator precedence.
- Do not change existing `+`, `-`, `*`, comparison, `+=`, `-=`, `for`, `while`,
  or return behavior except where `*=` becomes a valid statement.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C simple and readable.

    c_code = compile_source("""fn main() {
    let count = 3
    count *= 2
    print(count)

    self.assertIn("int count = 3;", c_code)

    self.assertIn('printf("%d\\n", count);', c_code)
