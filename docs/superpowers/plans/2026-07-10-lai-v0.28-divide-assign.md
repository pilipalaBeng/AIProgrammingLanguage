# LAI v0.28 Divide Assignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add minimal integer `/=` assignment sugar.

**Architecture:** Add `DivideAssignStmt` beside existing compound assignment
nodes. Tokenize `/=` as `SLASH_EQUAL` after preserving `//` comments, parse it
as a statement, validate the target and value as `int`, reject obvious static
zero divisors, and lower to explicit C assignment `name = name / value;`.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C
backend, local `clang`.

## Global Constraints

- Add `/=` statements only.
- Reuse existing `+=`, `-=`, `*=`, and ordinary `/` behavior and error style.
- Reject obvious static zero divisors such as `count /= 0` and `count /= (0)`.
- Do not add `%`, `%=`, `count++`, floating-point numbers, negative integers,
  unary minus, dynamic runtime division-by-zero checks, assignment expressions,
  or full operator precedence.
- Do not change existing `+`, `-`, `*`, `/`, comparison, `+=`, `-=`, `*=`,
  `for`, `while`, or return behavior except where `/=` becomes a valid
  statement.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C simple and readable.
