# LAI v0.20 For Step Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add optional positive forward `step` support to existing counted `for` loops.

**Architecture:** Extend the existing `ForStmt` AST with an optional `step` expression, teach the lexer/parser the `step` keyword, validate `step` as an `int` expression, and emit C `for` loops that increment by the provided step. Keep old `for i from start to end` behavior unchanged.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Only add optional `step` to existing `for i from start to end`.
- Do not add reverse loops, negative numbers, inclusive-end loops, `for item in list`, range expressions, ordinary subtraction, parentheses, or operator precedence.
- `to` remains exclusive.
- Omitted `step` remains equivalent to `step 1`.
- `start`, `end`, and `step` must be `int`.
- Reject explicit static `step 0`.
- Do not add new Python dependencies.
- Write failing tests before production changes.

- [x] **Step 1: Extend AST**

Change `ForStmt` to:

```python
@dataclass(frozen=True)
class ForStmt(Stmt):
    name: str
    start: "Expr"
    end: "Expr"
    statements: list["Stmt"]
    line: int
    step: "Expr | None" = None
```

- [x] **Step 2: Tokenize `step`**

Add:

```python
"step": "STEP",
```

to `_KEYWORDS`.

- [x] **Step 3: Parse optional step**

In `_parse_for_statement(...)`, after parsing the `to` expression:

```python
step = None
if self._match("STEP"):
    step = self._parse_expr(allow_string=False, allow_name=True)
...
return ForStmt(name.value, start, end, statements, for_token.line, step)
```

- [x] **Step 4: Check step**

Add a helper that validates:

- missing step is allowed
- step type is `int`
- static zero step is rejected

Use it from both normal `ForStmt` checking and returning-function `ForStmt` checking.

- [x] **Step 5: Generate C**

In `lai_c_backend.py`, use `1` when `statement.step is None`; otherwise use `_expr_to_c_value(statement.step, ...)` after checking it is `int` and not static zero. Emit:

```python

```
