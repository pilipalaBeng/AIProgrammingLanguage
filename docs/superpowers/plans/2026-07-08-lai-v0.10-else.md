# LAI v0.10 Else 语法实施计划

最后更新：2026-07-08

## 目标

在不扩大控制流范围的前提下，为现有 `if` 增加可选 `else` 分支。

## 步骤

1. 整理未提交实验，确保主线代码从 v0.9 干净基线开始。
2. 为 `else` 写测试：
   - `if true { ... } else { ... }` 能生成 C。
   - `else` 可以写在右花括号下一行。
   - then 分支变量不能在 else 分支中使用。
   - parser 能生成带 `else_statements` 的共享 AST 节点。
3. 修改 `lai_ast.py`：
   - `IfStmt` 增加 `else_statements` 可选字段。
4. 修改 `lai_compiler.py`：
   - lexer 增加 `else` 关键字。
   - parser 在 if then 块后解析可选 else 块。
   - CLI 帮助文本更新到 v0.10。
5. 修改 `lai_checker.py`：
   - 检查 then/else 分支。
   - 分支使用独立符号表副本。
6. 修改 `lai_c_backend.py`：
   - 生成 `} else {` 分支代码。
   - 后端符号表规则与 checker 保持一致。
7. 更新 `main.ly`、README、`AGENTS.md`、`docs/ai` 和版本路线图。
8. 运行完整单元测试和端到端编译。
9. 提交并推送。

## 验收结果

- `else` 成为 v0.10 的唯一新增用户语法。
- 不支持 `else if`、循环、函数参数或返回值。
- 文档同步记录当前版本和下一步方向。
