# LAI v0.25 Multiplication Expressions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ordinary integer multiplication expressions with minimal arithmetic precedence.

**Architecture:** Add `MultiplyExpr` beside the existing arithmetic AST nodes. Tokenize `*` as `STAR`, add a multiplication parser layer below `+` / `-`, validate all factors as `int`, and emit readable C joined by ` * `.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Add `*` multiplication expressions only.
- `*` binds tighter than `+` and `-`; parentheses continue to override grouping.
- Do not add `*=`, `/`, `/=`, `%`, `count++`, negative integers, unary minus, string repetition, logical operators, or full operator precedence.
- Do not change existing `+`, `-`, comparison, `+=`, `-=`, `for`, `while`, or return behavior except where multiplication becomes a valid integer subexpression.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C simple and readable.

```python
def _parse_multiply_expr(self, allow_string: bool, allow_name: bool) -> Expr:
    expr = self._parse_primary_expr(allow_string, allow_name)

    while self._match("STAR"):
        right = self._parse_primary_expr(allow_string, allow_name)
        if isinstance(expr, MultiplyExpr):
            expr = MultiplyExpr([*expr.factors, right])
        else:
            expr = MultiplyExpr([expr, right])

    return expr
```

if isinstance(expr, MultiplyExpr):
    c_factors: list[str] = []
