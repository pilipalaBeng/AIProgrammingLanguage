# LAI Array Element Assignment Implementation Plan

> 使用测试先行与子代理协作逐项实施；用户已确认方案 A，无需重复确认既定语法。

**Goal:** 完成 v0.40 第一阶段数组元素普通/复合赋值，不实现长度 API 或遍历。

**Architecture:** IndexAssignStmt 描述下标写入，checker 复用索引类型/边界检查，C backend 用地址、旧值和右值临时量按顺序单次求值，复用 checked i32 helper。

**Tech Stack:** Python 标准库、unittest、C、clang、受限文本 LLVM。

## Global Constraints

三种基础数组允许同类型 `=`；五种复合赋值仅 int。长度固定；先检查索引再求右值；算术或越界失败不写入。既有作用域、关键字、AST 构造与 LLVM 能力边界保持不变。外部知识库不操作。
