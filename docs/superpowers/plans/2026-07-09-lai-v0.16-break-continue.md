# LAI v0.16 Break And Continue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `break` and `continue` for the existing `while` loop.

**Architecture:** Extend the shared AST with `BreakStmt` and `ContinueStmt`. Parser recognizes standalone `break` and `continue` statements. Checker tracks loop nesting with `loop_depth` and rejects both statements outside loops. C backend emits direct `break;` and `continue;` statements.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Keep `fn main()` parameterless and returnless.
- Do not add `for`, labeled break/continue, multi-level loop jumps, `count++`, `+=`, or loop return analysis.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Preserve current `.ly -> C -> clang -> exe` pipeline.

        if count < 2 {
            continue
        }
