# LAI v0.21 Through Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add inclusive-end counted loops using `through`.

**Architecture:** Extend the existing `ForStmt` with an `inclusive_end` flag, teach the lexer/parser the `through` keyword, preserve all existing type checks, and choose `<` or `<=` in the C backend. Keep `to` exclusive.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- `to` remains exclusive.
- `through` is inclusive.
- Only support forward counted loops.
- Do not add reverse loops, negative numbers, range expressions, collection iteration, ordinary subtraction, parentheses, or operator precedence.
- `start`, `end`, and `step` must be `int`.
- Explicit static `step 0` remains rejected.
- Do not add new Python dependencies.
- Write failing tests before production changes.

    inclusive_end = True
