# LAI v0.38 General Early Return Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace final-statement-shape checks with lightweight control-flow outcomes so returning functions support guard clauses, reject unreachable statements consistently, and accept only statically proven `while true` all-return loops.

**Architecture:** `lai_checker.py` owns an internal immutable `FlowOutcome` result set. Every statement returns possible exits; blocks compose them in source order and reject the first statement reached without `FALLTHROUGH`. Branches union outcomes, loops consume their own `BREAK`/`CONTINUE`, and returning functions pass only when the final result is exactly `{RETURN}`. Parser, AST, C lowering, and the experimental LLVM capability boundary stay unchanged.

**Tech Stack:** Python 3, `unittest`, generated C17-compatible source, `clang`, PowerShell, Git.

**Status:** Ready for implementation.

## Global Constraints

- Plan base commit: `c2feb320c5452a3297b90b37954b44dfa369612d`.
- Follow `docs/superpowers/specs/2026-07-29-lai-v0.38-general-early-return-design.md` exactly.
- Add no token, parser rule, AST node, public language API, dependency, CFG module, or backend abstraction.
- Keep `return expr` forbidden in `main` and functions without a return type; do not add bare `return`.
- Returning functions pass only when every reachable path returns: final outcomes must be exactly `{RETURN}`. `DIVERGE` does not satisfy this contract.
- Reject the first statement reached without any `FALLTHROUGH` path as exactly `line N: unreachable statement`; do not inspect errors inside that unreachable statement.
- Keep the missing-return diagnostic exactly `line N: function <name> must end with return`.
- Preserve existing scope copies, expression/type checks, positive `for step` checks, and nearest-loop `break`/`continue` behavior.
- Only exact `true` and nested `GroupExpr` wrappers around it count as statically true. Do not fold `not false`, comparisons, calls, or general logic.
- Every `for` and every non-static-true `while` remains possibly zero-iteration and therefore has `FALLTHROUGH`.
- C backend behavior is unchanged; LLVM continues rejecting user functions and control flow with its existing capability errors.
- Keep new behavioral tests in `tests/test_lai_flow.py`; modify old tests only where v0.38 intentionally changes their expected result.
- Stage only intended files. Never stage `build/`, `examples/build/`, executables, `.superpowers/sdd/`, credentials, or unrelated user changes.
- After every task: run focused tests, full `python -m unittest discover -v`, and `git diff --check`; inspect the exact diff, obtain an independent review, fix findings, commit one logical change, and push `main`.

- [ ] **Step 2: Write failing conservative-boundary tests**

- `while ready { return 1 }`;
- `while true { if ready { return 1 } }` because the false path diverges;
- `while true { continue }`;
- `while true { if ready { break } return 1 }` because a break path falls through;
- `while not false { return 1 }` because v0.38 does not fold logic;
- `for i from 0 through 0 { return i }` because v0.38 does not prove non-empty ranges.

Add nesting tests:

- an inner-loop `break` is consumed by the inner loop and does not become an outer-loop `break`;
- a reachable `break` targeting the outer static loop prevents guaranteed return;
- a non-static outer `while` or `for` preserves `DIVERGE` from an entered inner static loop, so a
  fallback `return` does not falsely satisfy the all-path return rule;
- a `continue` or body fallthrough path creates `DIVERGE`, so a later same-block statement after the
  static loop is unreachable even though the function still fails the all-return contract when the
  loop is final.

3. For static-true `while`, map body outcomes exactly as specified. Do not inspect condition values

4. Ensure nested-loop `BREAK` and `CONTINUE` have already been consumed by the inner loop result.
5. Keep `DIVERGE` visible to block composition so statements after an all-terminal static loop are
