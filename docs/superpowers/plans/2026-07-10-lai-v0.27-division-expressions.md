# LAI v0.27 Division Expressions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ordinary integer division expressions.

**Architecture:** Add `DivideExpr` beside existing arithmetic AST nodes.
Tokenize `/` as `SLASH` after preserving `//` comments, parse it in the same
precedence layer as `*`, validate both operands as `int`, reject obvious static
zero denominators, and emit readable C using `/`.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C
backend, local `clang`.

## Global Constraints

- Add `/` division expressions only.
- `/` shares precedence with `*` and binds tighter than `+` / `-`.
- `int / int` returns `int` using C integer division semantics for now.
- Reject obvious static zero denominators such as `8 / 0` and `8 / (0)`.
- Do not add `/=`, `%`, `%=`, floating-point numbers, negative integers, unary
  minus, dynamic runtime division-by-zero checks, `count++`, logical operators,
  assignment expressions, or full operator precedence.
- Do not change existing `+`, `-`, `*`, comparison, `+=`, `-=`, `*=`, `for`,
  `while`, or return behavior except where division becomes a valid integer
  subexpression.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C simple and readable.

```python
if isinstance(expr, DivideExpr):
    left_kind = _infer_expr_type(expr.left, symbols, line, function_signatures)
    right_kind = _infer_expr_type(expr.right, symbols, line, function_signatures)
    if left_kind != "int" or right_kind != "int":
        raise LaiCompileError(
            f"line {line}: division operands must both be int, "
            f"got {left_kind} and {right_kind}"

        raise LaiCompileError(f"line {line}: division by zero")
    return "int"
```

```python
def _is_static_zero_expr(expr) -> bool:
    if isinstance(expr, IntExpr):
        return expr.value == 0
    if isinstance(expr, GroupExpr):
        return _is_static_zero_expr(expr.value)
    return False
```
