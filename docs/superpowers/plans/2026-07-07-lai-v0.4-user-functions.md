# LAI v0.4 用户自定义函数实施计划

日期：2026-07-07

## 实施步骤

1. 先在 `tests/test_lai_compiler.py` 增加 v0.4 行为测试。
2. 确认测试红灯：旧 parser 只能接受 `fn main`，函数调用是 unsupported statement。
3. 在 AST 中增加 `FunctionDef` 和 `CallStmt`，并让 `Program` 记录用户函数列表。
4. 改 parser：
   - 顶层解析多个 `fn`。
   - 要求存在 `main`。
   - 拒绝重复函数名。
   - 在语句层支持 `name()` 调用。
5. 改 C codegen：
   - 收集用户函数名。
   - 生成 `static void name(void);` 原型。
   - 生成用户函数体。
   - 每个函数使用独立变量符号表。
   - 调用不存在的用户函数时报错。
6. 更新 `main.lai`、README、路线图和 `docs/ai` 项目记忆。
7. 运行单元测试和端到端编译运行。

## 验收命令

```powershell
python -m unittest tests.test_lai_compiler -v
python lai_compiler.py main.lai --run
```
