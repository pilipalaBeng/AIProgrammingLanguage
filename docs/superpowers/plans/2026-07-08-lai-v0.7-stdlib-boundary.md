# LAI v0.7 小型标准库边界实施计划

日期：2026-07-08

## 实施步骤

1. 新增 `tests/test_lai_stdlib.py`。
2. 写入标准库辅助模块的期望行为：
   - `c_preamble()` 返回 `#include <stdio.h>`。
   - `escape_c_string()` 处理反斜杠、双引号、换行、回车和制表符。
   - `c_print_string_literal()` 为字符串字面量追加换行并生成 `printf`。
   - `c_print_value()` 为 `string`、`int`、`bool` 生成对应 `printf`。
3. 运行测试确认红灯：`lai_stdlib` 模块不存在。
4. 新增 `lai_stdlib.py`，实现最小 helper。
5. 修改 `lai_compiler.py`：
   - 从 `lai_stdlib.py` 导入 helper。
   - `generate_c()` 使用 `c_preamble()`。
   - `_print_stmt_to_c()` 使用 `c_print_string_literal()` 和 `c_print_value()`。
   - `_escape_c_string()` 保留为兼容包装，委托给 `escape_c_string()`。
6. 同步 README、路线图、`docs/ai` 项目记忆和 `AGENTS.md`。
7. 运行单元测试和端到端示例。

## 验收命令

```powershell
python -m unittest discover -v
python lai_compiler.py main.ly --run
```

## 验收标准

- 所有单元测试通过。
- `python lai_compiler.py main.ly --run` 可以生成并运行 `build/main.exe`。
- 生成的 C 代码行为与 v0.6 保持兼容。
- 文档中的当前版本和编译链路同步到 v0.7。
