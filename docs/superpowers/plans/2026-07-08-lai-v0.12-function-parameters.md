# LAI v0.12 Function Parameters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add typed parameters to zero-return user functions.

**Architecture:** Extend shared AST nodes with `Param` and call arguments. Parser reads parameter lists and call arguments; checker owns function signatures and argument validation; C backend maps LAI parameter types to C parameter declarations and emits argument expressions.

**Tech Stack:** Python 3.12+, standard-library `unittest`, LAI `.ly` sources, C backend compiled by `clang`.

## Global Constraints

- Only parameter types `string`, `int`, and `bool` are supported.
- `fn main()` must remain parameterless.
- Function calls remain statements only.
- Do not add return values, `return`, default arguments, named arguments, varargs, overloads, or function-call expressions.
- Keep `compile_source(source: str) -> str` as the primary test entry.
