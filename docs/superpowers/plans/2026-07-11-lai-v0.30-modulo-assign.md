# LAI v0.30 Modulo Assignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `%=` modulo assignment statements.

**Architecture:** Add `ModuloAssignStmt` beside the existing compound assignment
AST nodes. Tokenize `%=` as `PERCENT_EQUAL`, parse it as a statement-level
compound assignment, validate an existing `int` target and `int` RHS, reject
obvious static zero RHS values, and emit readable C as `name = name % value;`.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C
backend, local `clang`.

## Global Constraints

- Add `%=` modulo assignment statements only.
- `count %= expr` is equivalent to `count = count % expr`.
- The left side must be an existing `int` variable or parameter.
- The right side must be an `int` expression.
- Reject obvious static zero right-hand values such as `count %= 0` and
  `count %= (0)`.
- Do not change ordinary `%`, `*`, `/`, `+`, `-`, comparison, `+=`, `-=`,
  `*=`, `/=`, loop, branch, or return behavior except where `%=` becomes a
  valid statement.
- Do not add `count++`, floating-point numbers, negative integers, unary minus,
  dynamic runtime modulo-by-zero checks, logical operators, assignment
  expressions, full operator precedence, or LLVM IR changes.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Keep generated C simple and readable.

- [x] **Step 5: Check modulo assignment**

In `_check_statement(...)`, add logic mirroring `/=`:

```python
if isinstance(statement, ModuloAssignStmt):
    if not NAME_RE.match(statement.name):
        raise LaiCompileError(
            f"line {statement.line}: invalid variable name: {statement.name}"
        )
    if statement.name not in symbols:
        raise LaiCompileError(f"line {statement.line}: unknown variable: {statement.name}")
    expected_type = symbols[statement.name]
    if expected_type != "int":
        raise LaiCompileError(
            f"line {statement.line}: cannot use %= with {statement.name} "
            f"of type {expected_type}"
        )
    actual_type = _infer_expr_type(
        statement.value, symbols, statement.line, function_signatures
    )
    if actual_type != "int":
        raise LaiCompileError(
            f"line {statement.line}: %= value must be int, got {actual_type}"
        )
    if _is_static_zero_expr(statement.value):
        raise LaiCompileError(f"line {statement.line}: modulo by zero")
    return
```
