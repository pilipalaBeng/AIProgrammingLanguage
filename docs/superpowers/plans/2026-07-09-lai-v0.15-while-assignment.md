# LAI v0.15 While And Assignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a minimal usable loop with `while condition { ... }` and assignment `name = expr`.

**Architecture:** Extend the shared AST with `WhileStmt` and `AssignStmt`. Parser recognizes `while` and distinguishes `name(...)` calls from `name = expr` assignments. Checker enforces boolean loop conditions and assignment type stability. C backend emits readable `while` blocks and assignment statements.

**Tech Stack:** Python 3.12+, `unittest`, existing LAI lexer/parser/checker/C backend, local `clang`.

## Global Constraints

- Keep `fn main()` parameterless and returnless.
- Do not add `for`, `break`, `continue`, `count++`, `+=`, or loop return analysis.
- Do not add new Python dependencies.
- Write failing tests before production changes.
- Preserve current `.ly -> C -> clang -> exe` pipeline.

- [x] **Step 1: Add success tests**

Add tests that expect:

```python
def test_while_loop_with_assignment(self):
    c_code = compile_source("""fn main() {
    let count = 0
    while count < 3 {
        print(count)
        count = count + 1
    }
}""")

    self.assertIn("while (count < 3) {", c_code)
    self.assertIn("count = count + 1;", c_code)
```

```python
def test_function_parameter_can_be_reassigned(self):
    c_code = compile_source("""fn bump(count: int) {
    count = count + 1
    print(count)
}

fn main() {
    bump(1)
}""")

    self.assertIn("count = count + 1;", c_code)
```
